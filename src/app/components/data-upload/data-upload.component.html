Help: Data Format

Upload a CantusCorpus v1.0 chants.csv (same columns as Export to CSV on Chant list, under the table; select chants first). Cantus Corpus v0.2 format / old ChantLab files are also accepted. Extra columns are ignored; missing ones are stored empty.

v1.0 columns (* required in CantusCorpus; optional here):

chantlink*, incipit*, cantus_id*, mode, siglum*, position, folio*, sequence, feast, feast_code, genre, office, srclink*, melody_id, full_text, melody, db*, image

Example row

https://cantus.uwaterloo.ca/chant/493007,A timore inimici eripe domine,1196,2,NL-Uu 406,1.5,048r,14,Fer. 4 per annum,04004000,A,M,https://cantus.uwaterloo.ca/source/573,,A timore inimici eripe domine animam meam,1---f---f--fE--d---f--f--fe--d---d--c--d---f--f--f---f--e--fE---d--d---4,CD,

Aliases mapped automatically:

  • id / drupal_path → chantlink
  • source_id → srclink
  • notes → image
  • volpiano → melody
  • feast_id / genre_id / office_id → feast / genre / office

Numeric id is ignored. dataset_name in the file is replaced by the name you type above.
